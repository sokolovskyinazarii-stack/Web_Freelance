# FreelanceHub

Платформа для фрілансу на **Express.js**, **Prisma** та **SQLite**.

## Предметна область

Платформа для фрілансу: фрілансер, замовник, проєкт, категорія, замовлення, статус, доставка, кур’єр.

## Стек

- Node.js + Express.js 5
- Prisma ORM 6
- SQLite (файл `prisma/freelance.db`)
- Vanilla JavaScript, CSS та SVG-іконки без UI-фреймворків

## Запуск

```bash
npm install
npm start
```

Після запуску відкрити `http://localhost:4000`.

Під час старту сервер:

1. виконує `prisma db push` і створює SQLite-базу, якщо її ще немає;
2. перевіряє, чи база порожня;
3. додає демонстраційні записи;
4. запускає Express на порту `4000`.

Повторний запуск не дублює дані. Щоб створити базу заново, достатньо видалити `prisma/freelance.db`.

## Модель даних

| Сутність | Призначення | Зв’язки |
| --- | --- | --- |
| `Freelancer` | виконавець | проєкти, замовлення |
| `Customer` | замовник | проєкти, замовлення |
| `Category` | напрям робіт | проєкти |
| `Project` | проєкт | категорія, замовник, фрілансер, замовлення |
| `Order` | угода | проєкт, замовник, фрілансер, статус, доставка |
| `Status` | статус замовлення | замовлення |
| `Courier` | кур’єр | доставки |
| `Delivery` | доставка | замовлення, кур’єр |

Зв’язки реалізовано через зовнішні ключі Prisma, індекси додано для полів фільтрації.

## Демонстраційні дані

У базі є 6 фрілансерів, 5 замовників, 6 категорій, 8 проєктів, 10 замовлень, 6 статусів, 4 кур’єри та 4 доставки. Дані зберігаються у `src/db/seed-data`.

## REST API

| Метод | Шлях | Опис |
| --- | --- | --- |
| GET | `/api/overview` | агрегована статистика для панелі |
| GET | `/api/freelancers` | список фрілансерів |
| GET | `/api/freelancers/:id` | один фрілансер із проєктами та замовленнями |
| GET | `/api/customers` | список замовників |
| GET | `/api/categories` | список категорій |
| GET | `/api/projects` | список проєктів |
| GET | `/api/orders` | список замовлень |
| GET | `/api/statuses` | довідник статусів |
| GET | `/api/deliveries` | список доставок |
| GET | `/api/couriers` | список кур’єрів |

Для кожної сутності також працює `GET /api/<resource>/:id`.

## Інтерфейс

Односторінкова панель із hash-навігацією:

- `#/` — огляд платформи;
- `#/freelancers`, `#/customers`, `#/projects`, `#/categories`;
- `#/orders`, `#/statuses`, `#/deliveries`, `#/couriers`;
- `#/<resource>/:id` — сторінка перегляду запису.

Для кожного списку є пошук, а для кожного запису — сторінка з деталями та пов’язаними сутностями.

## Структура

```text
prisma/

  db/           Prisma Client, bootstrap, seed
  public/       інтерфейс: HTML, CSS, JS
  routes/       REST-маршрути
  app.js
  server.js
```
